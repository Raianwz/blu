# Catálogos de ícones

Os catálogos Blû, customizados, Bootstrap Icons, Material Icons e Lucide ficam em
subpastas próprias. As licenças das bibliotecas acompanham seus arquivos.

O carregamento dos scripts é definido em `js/loader.js` e `share.html`; os
arquivos usados offline também constam em `js/service-worker.js`. Os IDs dos
ícones salvos nos dados do usuário não dependem dos caminhos dos arquivos.
